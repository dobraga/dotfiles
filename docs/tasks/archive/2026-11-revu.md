# Plan: `revu` — Minimalist Plannotator + Crit Review Tool

**Repo:** `/home/dobraga/src/dotfiles` (`master`)
**Stack:** TypeScript + Bun (zero runtime npm dependencies, zero build step)
**CLI:** `revu` (`~/.local/bin/revu` -> `~/src/dotfiles/tools/revu/bin/revu`)

## Scope
- `tools/revu/`: Core CLI, session/snapshot engine, Git & round-to-round diff engine, HTTP/SSE server, loopback HTML/live reverse proxy with DOM pin overlay, embedded MCP stdio server, Claude Code & Antigravity (AGY) plan-mode hooks, offline vanilla web UI, and `bun test` suite.
- `skills/revu/SKILL.md`: Universal agent skill (linked to `~/.claude/skills/` and `~/.gemini/skills/`).
- `tools/revu/scripts/merge-configs.ts` + `install_dotfiles.sh`: Non-destructive config registration for Claude Code, AGY hooks, and MCP servers.
